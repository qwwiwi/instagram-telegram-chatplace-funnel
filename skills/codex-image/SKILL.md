# codex-image – картинки по подписке Codex

Скрипт `scripts/codex_image.py` вызывает инструмент `image_generation` через Codex-бэкенд, используя
вход по подписке (`codex login`). Ключ API и оплата за картинку не нужны; квота общая с подпиской Codex.
Платный API-путь в этот репозиторий намеренно не включён.

## Установка (один раз)

```bash
npm install -g @openai/codex     # Codex CLI
codex login                      # вход своей подпиской ChatGPT (на сервере: codex login --device-auth)
```

Токен сохраняется в `~/.codex/auth.json` – скрипт читает его оттуда, ничего не печатает и никуда не копирует.

Для Claude Code удобно поставить официальный плагин Codex: https://github.com/openai/codex-plugin-cc
(`/plugin marketplace add openai/codex-plugin-cc`, затем `/plugin install codex@openai-codex` и `/codex:setup`).
Сам плагин картинки не рисует: он настраивает тот же вход, который использует этот скрипт.

Первый запуск `scripts/run.sh` создаёт рядом виртуальное окружение `.venv` и ставит туда пакет `openai`
(папка `.venv` в `.gitignore`).

## Быстрый старт

```bash
scripts/run.sh "prompt in English" [quality] [aspect] [ref1.png ... ref5.png]
```

| Параметр | Значения |
|---|---|
| quality | `low` (~45 с), `medium` (по умолчанию, 1–2 мин), `high` (2–3 мин) |
| aspect | `landscape` 1536x1024, `square` 1024x1024, `portrait` 1024x1536 |
| refN | до 5 локальных файлов png/jpg/webp, до 15 МБ каждый, до 40 МБ суммарно |

Скрипт печатает путь к PNG (по умолчанию `~/.codex/cache/images/img_<время>.png`). Промпт лучше писать по-английски;
точный русский текст для надписи кладите в кавычки внутри промпта.

## Сначала бриф (ТЗ), потом генерация

Модель лучше всего работает со структурным брифом и референсами. Порядок:

1. `python3 scripts/brief.py questions --type banner` – вопросы заказчику (себе или клиенту). Типы: `youtube-cover`,
   `banner`, `post-illustration`, `infographic`, `sticker`, `logo`, `other`.
2. `python3 scripts/brief.py init brief.json --type banner` – шаблон, заполните его.
3. `python3 scripts/brief.py check brief.json` – должен вернуть код 0; иначе выводит, что уточнить.
4. `python3 scripts/brief.py prompt brief.json` – печатает английский промпт и готовую команду `run.sh`.
5. Запустите команду, откройте картинку и проверьте: текст написан дословно и по одному разу, нет лишних надписей.

Пример брифа: `examples/banner.brief.json`. Пресеты бренда (общие референсы) – `references/brands.json`,
формат показан в `references/brands.example.json`.

## Жёсткие ограничения подписочного пути (иначе HTTP 400)

- Только Responses API + инструмент `image_generation`; `client.images.generate()` – это путь с API-ключом, подписка его не принимает.
- `stream=True` и `store=False` обязательны; `input` – список сообщений, не голая строка.
- Референсы – блоки `input_image` (data URL) рядом с `input_text`; максимум 5.
- Размер только из трёх: 1536x1024, 1024x1024, 1024x1536. Нужен другой размер (например 1280x720) – обрежьте после генерации.
- Модель-«хозяин», которая вызывает инструмент, задаётся переменной `CODEX_IMAGE_HOST_MODEL`; значение по умолчанию в
  скрипте взято из исходников – проверьте актуальное название модели в вашем Codex.
- Нет seed, нет масок, нет прозрачности как опции, нет n>1.

## Если что-то не работает

| Симптом | Что делать |
|---|---|
| `ModuleNotFoundError: openai` | запускайте через `scripts/run.sh`, а не системным python3 |
| `Codex auth не найден` | `codex login` |
| HTTP 400 | проверьте stream/store и форму `input` |
| 401/403 | токен устарел – повторите `codex login` |
| В потоке нет картинки | модель отказала по политике – переформулируйте |
| референс отклонён | только png/jpg/webp, не больше 5 файлов |

## Когда не использовать

Точная типографика, диаграммы, логотип «в точности как есть» – рисуйте вручную (SVG/HTML → PNG, см. `funnel-banners`).
Фото реальных людей: используйте только свои фото и не просите модель «улучшать» лицо.

Использование неофициального входа по подписке регулируется условиями OpenAI – проверьте их для своего тарифа.

# Кодовые слова Instagram

> Используете другой сервис, а не ChatPlace? Не отказывайтесь: набор адаптируется, см. `docs/ADAPTING.md` в корне репозитория.

Кодовое слово – это слово, которое зритель пишет в комментарии под постом или рилсом («Напиши ГАЙД в комментариях»).
ChatPlace видит слово, отвечает публично под комментарием и пишет человеку в директ. Дальше человек идёт в
Telegram-бота и получает материал (скиллы `telegram-bot-setup` и `chatplace-funnels`).

```
пост или рилс: «Напиши ГАЙД в комментариях»
  -> комментарий «гайд» (или сообщение «гайд» в директ)
  -> публичный ответ под комментарием (ротация коротких вариантов)
  -> директ 1: баннер + крючок + кнопка «Хочу гайд»
  -> директ 2: «Лови гайд…» + кнопка-ссылка на бота: https://t.me/your_bot?start=gayd_ig
  -> напоминание, если человек не нажал кнопку (необязательно)
```

Telegram-часть описана в `telegram-bot-setup`; сборка воронки скриптом – в `chatplace-funnels`.

## Правила слова

1. **Одно слово = одна воронка.** Тогда по каждому слову видно, сколько людей пришло и сколько подписалось.
2. **Одно слово без пробелов и знаков**, короткое, легко набирается с телефона, по смыслу связано с обещанием.
3. **Слово не должно пересекаться с другими.** ChatPlace не даёт использовать одно написание в двух автоматизациях
   («The keyword is already used in another automation»). Если один из триггеров работает по схеме «содержит»
   (`commentContains`), слово, которое входит в другое слово, будет срабатывать на оба – проверьте это тестом.
4. **Латинский slug к слову** (`гайд` -> `gayd`): он нужен для ссылки бота (`?start=gayd_ig`) и для имени инвайта.
   Кириллица в параметре `start` не проходит.
5. **Слово ставьте в подпись текстом**: «Напиши ГАЙД в комментариях». Призыв только на картинке работает хуже.
6. **Обещание в директе = то, что выдаёт бот.** Не обещайте «видео-гайд», если в боте страница с кейсами.
7. В директе без цен и без рассказов про «пассивный доход». Тире – короткое «–».

## Написания слова

Триггер по комментарию и по сообщению чувствителен к написанию, поэтому заводите регистры: `ГАЙД`, `Гайд`, `гайд`.
Если слово можно написать латиницей (guide) – добавьте и её. В публичной инструкции ChatPlace-скилла рекомендовано
не меньше 7 написаний суммарно для слова с английским вариантом; для обычного русского слова хватило трёх.

Важная особенность из практики: если передать в `automations_quick_setup` сразу несколько кириллических написаний,
бывает ошибка «The keyword is already used in another automation». Поэтому скрипт `codeword.py` создаёт воронку с
одним написанием, а остальные добавляет по одному через `automations_triggers_set` (набор каждый раз полный и растёт).

## Триггеры

Для Instagram доступны `messageContains`, `messageEquals`, `messageAnyValue`, `commentContains`, `commentEquals`,
`commentAnyValue`, `storyReaction`, `storyMention`, `storyReply` и варианты для прямого эфира. В Telegram-боте
триггеров по комментариям нет – только три «message»-типа. По умолчанию используем пару
`commentContains` + `messageEquals`: слово в комментарии или точное слово в директе.

## Тексты

**Директ 1 (крючок).** Короткий вопрос про боль, одна фраза про пользу, призыв нажать кнопку:

```
Привет! Хочешь собрать первого AI-агента, но не знаешь, с чего начать?

В гайде показываю путь по шагам.

Жми «Хочу гайд».
```

Ссылок в первом сообщении нет: ссылка приходит только вторым сообщением, после нажатия (так безопаснее для Instagram).

**Директ 2 (ссылка).**

```
Лови гайд «Первый AI-агент».

Ссылка – по кнопке ниже, забирай.
```

Кнопка-ссылка ведёт на бота (`https://t.me/your_bot?start=gayd_ig`) или на короткую ссылку (`funnel-links`).

**Публичные ответы под комментарием.** 15 разных вариантов по 2–4 слова, без эмодзи и ссылок, например:
«Кинул в директ», «Смотри директ», «Отправил в личку», «Проверь сообщения». Instagram может счесть повторяющиеся
одинаковые ответы спамом, поэтому ротация обязательна; публичное правило ChatPlace-скилла требует минимум 3 варианта.

**Лимиты.** Текст директа – до 1000 знаков (из практики). Надпись на кнопке держите короткой; точный лимит кнопки
Instagram проверьте в документации ChatPlace.

**Напоминание.** Если человек не нажал кнопку, можно отправить одно напоминание («Гайд ещё ждёт – кнопка выше.»).
В `quick_setup` для него есть поле `reminderMessage`; как задать задержку и условие по метке клика –
проверьте в документации ChatPlace.

## Как создать слово

1. Заполните `funnel.json` по образцу `skills/chatplace-funnels/examples/codeword.example.json`.
2. `python3 skills/chatplace-funnels/scripts/codeword.py check funnel.json` – проверка правил (слово, slug, лимиты, ответы).
3. `... codeword.py create funnel.json --bot-id <ID бота Instagram> --dry-run` – посмотреть список вызовов.
4. `... codeword.py create funnel.json --bot-id <ID бота Instagram>` – создать. Воронка остаётся **на паузе**.
5. Откройте результат (`chatplace.py detail <id>`) и проверьте тексты, кнопки, написания, ссылку.

## Проверка слова до публикации поста

Не публикуйте пост, пока слово не прошло полный круг на тестовом аккаунте. Instagram-аккаунт не отвечает сам себе,
поэтому пишите с **второго** аккаунта.

1. Воронка создана, статус «на паузе», структура проверена командой `detail`.
2. Включите её (`chatplace.py status <id> active`) – на время теста.
3. Со второго аккаунта напишите слово комментарием под тестовым постом и отдельным сообщением в директ.
4. Проверьте: публичный ответ появился; в директ пришёл первый текст с баннером; кнопка «Хочу…» ведёт ко второму сообщению.
5. Повторите для каждого написания (`ГАЙД`, `Гайд`, `гайд`, латиница).
6. Нажмите кнопку-ссылку: открывается бот, `/start` приходит со словом (`gayd_ig`), в боте проходит подписка и выдача.
7. Если есть напоминание – убедитесь, что оно приходит один раз.
8. Только после этого публикуйте пост. Если что-то не так – верните `paused`, исправьте и повторите круг.

## Правки живого слова

- Перед правкой сохраните состояние: `chatplace.py backup <id> backups/gayd.json`.
- Меняйте только нужное; после правки снова `detail` и тест в директе – код 200 от API не доказывает, что человек увидит то, что вы задумали.
- Слов несколько – правьте по одному и проверяйте каждое.
- Включение, выключение и смену ссылки согласуйте с собой заранее: выпишите, что меняете и что не трогаете.

## Грабли

- Под комментарием тишина – нет правила публичного ответа (поле `autoAnswers` в `quick_setup`, либо отдельное правило
  `comments_create` – флаг `--comment-rule`).
- Кнопка рисуется серой пилюлей сбоку и ничего не открывает – блок создан как `QuickAnswer`; нужен `Template`
  (подробности в `chatplace-funnels`).
- Тексты в `<p>…</p>` после `quick_setup` – скрипт убирает обёртки сам.
- Слово ловится только в одном регистре – не добавлены остальные написания.
- Instagram-ссылки-кнопки имеют отслеживание кликов ChatPlace; условие напоминания читает метку клика – проверьте в документации ChatPlace.
- Статистика по слову: `chatplace.py analytics <id> --from ГГГГ-ММ-ДД --to ГГГГ-ММ-ДД` (поле `totalClients.currentPeriod`).

## Что в этом скилле не проверено

Тариф ChatPlace для доступа к API, место выдачи ключа в кабинете, формат задержки напоминания, точный лимит кнопки
Instagram и поведение `commentContains` на регистр – проверьте в документации ChatPlace.

# Баннеры воронки

> Используете другой сервис, а не ChatPlace? Не отказывайтесь: набор адаптируется, см. `docs/ADAPTING.md` в корне репозитория.

В воронке два баннера, и они должны выглядеть **заметно по-разному**:

| Баннер | Где | Задача |
|---|---|---|
| Баннер 1 – приветствие | директ 1 в Instagram и первое сообщение бота | зацепить и показать обещание |
| Баннер 2 – выдача | сообщение бота после проверки подписки | «доступ открыт», подтвердить, что обещание выполнено |

Чему научил опыт авторов (баннер выдачи пробовали три раза): та же обложка дважды – «обложки повторяются»; та же обложка
с другой надписью – «сливается»; 3D-картинка «подарочная коробка» от нейросети – «слишком ИИ-шная». Сработало: **спокойный
графичный баннер из HTML** в стиле бренда, где крупный текст «Доступ открыт», название материала и обложка материала справа.

## Какими инструментами делать

1. **Публичный скилл генерации баннеров:** https://github.com/qwwiwi/instagram-superpowers – ставится как отдельный скилл
   для Claude Code/Codex; подробности установки и запуска читайте в его README (в этом репозитории они не дублируются и не проверялись).
2. **`skills/codex-image`** (в этом репозитории): генерация картинки через подписку Codex/ChatGPT, без платного API.
   Бриф-инструмент `brief.py` собирает структурный промпт, `run.sh` рисует. Подходит для иллюстраций и обложек.
3. **HTML -> скриншот** (`scripts/render_banner.py` + `assets/delivery-template.html`): когда нужен точный русский текст.
   Кириллица в HTML гарантированно читаема, чего нельзя сказать о тексте, нарисованном моделью.

Платные API-пути для картинок в этот набор не входят. Если нужно больше 1536 px по длинной стороне, делайте баннер в HTML.

## Бриф до генерации

Прежде чем что-то рисовать, ответьте на вопросы (`python3 skills/codex-image/scripts/brief.py questions --type banner`):
зачем картинка; где будет показана (директ Instagram, бот Telegram, пост); размер; **точный текст** дословно; что в кадре;
фон и стиль (палитра, шрифт); референсы с ролями; чего не должно быть. Дальше:

```bash
python3 skills/codex-image/scripts/brief.py init brief.json --type banner
# заполните brief.json (пример: skills/codex-image/examples/banner.brief.json)
python3 skills/codex-image/scripts/brief.py check brief.json      # должен вернуть 0
python3 skills/codex-image/scripts/brief.py prompt brief.json     # промпт + команда run.sh
```

## Правила текста на баннере

- Текст короткий: заголовок не больше 4 слов. Должен читаться в миниатюре (около 320x180).
- Каждая надпись – дословно и **ровно один раз**; в промпте перечислите строки в кавычках и добавьте «no extra text».
- Стрелки `→` модель искажает – заменяйте словом или рисуйте в HTML.
- Один акцент: выделите одно ключевое слово плашкой или цветом.
- Контраст: светлый текст на тёмном фоне или наоборот; не кладите текст на пёструю часть картинки.
- Безопасные поля: держите текст дальше примерно 5 процентов от края, чтобы Instagram и Telegram ничего не обрезали.
- Обещание на баннере = обещание в тексте директа = то, что выдаёт бот.
- Логотип – только настоящий файл, не набирайте его текстом и не просите модель «перерисовать».
- Лицо автора – только его реальные фото как референсы; не просите модель «улучшить» лицо. Результат сравните с оригиналом,
  при заметном уходе от лица перегенерируйте.
- Без чужих брендов, водяных знаков и мелкого текста.

## Размеры

| Куда | Размер | Примечание |
|---|---|---|
| Баннер выдачи, HTML | 1280x720 (16:9) | размер шаблона `delivery-template.html` |
| Картинка в сообщение бота | квадрат 1080x1080 или 16:9 | в исходниках для бота использовали PNG 1080x1080 |
| Генерация по подписке Codex | 1536x1024, 1024x1024 или 1024x1536 | другой размер получают кадрированием после генерации |
| Пост-карусель, рилс | 1080x1350 (4:5), 1080x1920 (9:16) | общие требования Instagram – сверьте с актуальными |
| Обложка YouTube | 1920x1080 | кроп после генерации |

Какое соотношение сторон лучше всего показывает картинка в личном сообщении Instagram и бота – проверьте на тестовом аккаунте.

## Рендер баннера выдачи

```bash
export CHROME_BIN=/path/to/chromium      # любой Chrome/Chromium
python3 skills/funnel-banners/scripts/render_banner.py out/ \
  --brand "Your Brand" --sub "Гайд «Первый AI-агент»" --cover cover.jpg --png
```

Откройте `out/banner.png` и проверьте: нет обрезанного текста, подпись не наезжает на обложку, всё читается. Без `--png`
скрипт пишет только `banner.html` – откройте его в браузере и сделайте скриншот 1280x720 сами.
Шрифты в шаблоне – системные запасные; для фирменного шрифта подключите свой файл в `<style>`.

## Загрузка в ChatPlace

1. ChatPlace загружает медиа **только по публичному URL**. Выложите готовый jpg на любой хостинг статики, где у вас есть права
   (свой сервер, объектное хранилище, GitHub Pages) – адрес должен открываться без авторизации.
2. `python3 skills/chatplace-funnels/scripts/chatplace.py media-upload <URL> --platform telegram` (или `instagram`) –
   вернёт id медиа. Один id можно прикреплять к любому числу сообщений.
3. Картинка воронки Instagram – поле `photoId` в `funnel.json`; в Telegram – `welcome_media` и `after_media` в `gate.json`.
4. Замена картинки в готовом сообщении: `automations_messages_detach_media` (оба параметра: `messageId` и `mediaFileId`),
   затем `automations_messages_attach_media` с новым id. Просто `attach` без `detach` ответит «Message already has media attached».
5. После `attach` перечитайте `get_detail`: поле `hasMedia` должно быть `true` (иногда `attach` проходит без ошибки, а картинки нет).

Хранить у себя карту `{название баннера: id медиа}` удобно: в `get_detail` виден только `hasMedia`, а не текущий id.

## Чек-лист баннера

- [ ] Бриф заполнен, `brief.py check` вернул 0
- [ ] Текст дословный, без лишних надписей, читается в миниатюре
- [ ] Баннер 1 и баннер 2 заметно разные
- [ ] Размер подходит площадке, поля по краям свободны
- [ ] Картинка доступна по публичному URL, получен id медиа, `hasMedia: true`
